A standard-library Python program writes one original, 100-word fantasy-villain
speech to `entry.txt`. Edris tends the teeth of the worm that ate the first king,
then gives an arriving hero a job. The program needs no dependencies, network,
secrets, or input files.

## Run it

```sh
python3 main.py
```

The default target is `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose a
different output directory; the program creates it if needed without deleting
or replacing it. Each run overwrites only `entry.txt`, writes UTF-8 without a
trailing newline, and prints the word and character counts: **100 words, 502
characters**.

The ten concepts, three full drafts, ordered self-assessments, and post-run
revision are recorded in [DESIGN.md](DESIGN.md).
